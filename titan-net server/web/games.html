      Write a game

      The server keeps score for you, so write rules that rely on it: world variables, each player's statistics with the arithmetic and limits done server-side, what everyone carries and wears, dice rolls, and skill checks the server decides. Say what your game needs — "everyone starts with 12 hit points and a bow", "a locked door needs a strength check against 10" — and the game master will use the right one.

      Text files the game master reads as its rules. Name one "objects.something" or put it in a folder to make a catalogue the game master looks entities up in.
